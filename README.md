Olist Brazilian E-Commerce Analysis

📌 Project Overview

An end-to-end analysis of the Olist Brazilian E-Commerce dataset to understand sales performance, customer behavior, product categories, seller performance, and delivery trends.

The project combines SQL, Python (Pandas), and Power BI to transform raw e-commerce data into meaningful business insights and interactive dashboards.

🎯 Business Objectives

- Analyze overall sales and order performance
- Identify top-performing product categories
- Analyze revenue across customer states
- Understand customer purchasing behavior
- Evaluate seller performance
- Analyze order delivery time and late deliveries
- Identify key trends and patterns in the Brazilian e-commerce business

🛠️ Tools & Technologies

- SQL / MySQL – Data querying and business analysis
- Python / Pandas – Data analysis and exploration
- Power BI – Interactive dashboard and visualization
- Jupyter Notebook – Python analysis
- GitHub – Project documentation and version control

📊 Key Insights

Some of the key insights identified during the analysis include:

- Health & Beauty emerged as the top revenue-generating product category.
- São Paulo was the leading customer state by revenue.
- Customer and order analysis helped identify important purchasing patterns.
- Seller-level analysis was used to evaluate revenue and average order value.
- Delivery analysis was performed to understand average delivery time and late deliveries.
- Power BI was used to bring together sales, customer, product, seller, and delivery insights into an interactive dashboard.
